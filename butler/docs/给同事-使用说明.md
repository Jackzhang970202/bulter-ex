# 经验管家 · 同事使用说明

## 这是什么
在你正常用 Claude Code 干活时，它于后台悄悄记录会话；你点一次「复盘」，它会自动从
这些会话里提炼出"值得沉淀的经验规则"和"你的工作偏好画像"，你审批通过后，下次任何
项目的 Claude 会话都会自动带上这些规矩——不用你再反复叮嘱 AI。

## 前提
- Windows 电脑
- 已安装并登录 Claude Code CLI（提炼经验要用它跑一次无头分析，消耗少量额度）

## 安装（30 秒）
1. 把整个「经验管家-同事版」文件夹放到你喜欢的位置（如 `D:\butler`）
2. 双击里面的 `butler.exe`
   - 首次运行 Windows 可能弹蓝色 SmartScreen 提示 → 点「更多信息」→「仍要运行」
3. 任务栏右下角 ˄（隐藏图标浮窗）里会出现圆点图标：
   灰蓝=正常 / 黄数字=有东西等你审批 / 红=有问题 / 沙漏=复盘中
4. 双击这个托盘图标 = 打开大屏（浏览器页，可随时关闭，不影响运行）

## 日常用法（就三个动作）
| 什么时候 | 做什么 |
|---|---|
| 平时 | 什么都不用做，正常用 Claude Code。它自动发现你最近在用的项目，托盘亮角标 → 打开大屏在「项目接入」区点【接入】，之后那个项目的会话就会自动带上你的规则 |
| 攒了几天 | 大屏点一次「现在复盘」（或托盘菜单同项）。等 1~3 分钟，进度实时显示 |
| 复盘完 | 大屏「待审候选」区逐条看（每条可点【证据】回看你当时的原话），想要的点批准，不想要的拒绝。拒绝过的不会再烦你 |

已开着的 Claude 会话不用重启：它下次压缩/重开时自动带上新规；想立刻生效，
在那个会话里说一句「重新读发行版」。

## 数据与隐私（重要）
- 一切数据都在本文件夹的 `data/` 里：你的规则、画像、会话归档副本，**只在你机器上**
- 复盘提炼前，会先对内容做本地打码（密钥/密码/身份证/手机号/邮箱等才交给分析模型）
- 不想被记录时：托盘/大屏点「暂停采集 2h」
- 删除整个文件夹 = 彻底卸载（再到大屏把各项目「摘除」一下更干净）
- 这个软件不联网、不上传，唯一的外部调用是复盘时借用你已登录的 Claude Code

## 常见问题
- 双击没反应/秒退：确认没开着第二个实例（任务管理器搜 butler）；或查看
  `data/logs/run.log` 里的报错
- 托盘图标找不到：点任务栏右下角 ˄ 展开浮窗；想常驻显示：系统设置→个性化→任务栏
  →其它系统托盘图标→开启
- 大屏地址：http://127.0.0.1:8420
